# 使い方ガイド - 生活OS

---

## ブラウザで開く方法（PC）

1. エクスプローラーで `life-os` フォルダを開く
2. `index.html` をダブルクリックする
3. ブラウザで開いたらホーム画面が表示される

---

## GitHub Pages で公開する手順

1. GitHubにリポジトリを作成する（例：`life-os`）
2. `life-os` フォルダの中身を全部アップロードする
3. リポジトリの「Settings」→「Pages」→「Branch: main」→「/ (root)」を選んで保存
4. 数分後に `https://ユーザー名.github.io/life-os/` でアクセスできるようになる

---

## iPhoneのホーム画面に追加する手順

1. iPhoneのSafariで `https://ユーザー名.github.io/life-os/` を開く
2. 画面下の共有ボタン（四角から矢印が出るアイコン）をタップ
3. 「ホーム画面に追加」をタップ
4. 名前を「生活OS」のまま「追加」をタップ
5. ホーム画面にアイコンが追加される

> ホーム画面から開くとアドレスバーなしで全画面表示になる

---

## 各機能の使い方

### ⏰ リマインダー

- 右下の ＋ ボタンでリマインダーを追加
- タイトル・日付・優先度・繰り返しを設定する（日付は「今日／明日／来週」ボタンでも一発で設定可能）
- タイトルをスペース区切りで複数入力すると、それぞれ別々のリマインダーとして一括で追加される（例：「牛乳 卵 米」→3件。日付・優先度・繰り返しは共通で設定される）。編集時にスペース区切りで入力した場合も、1件目が編集対象を更新し、2件目以降は新規リマインダーとして追加される
- リストの丸いボタンを押すと完了になる
- 繰り返し設定済みは、完了を押すと次の日付に更新される
- 未完了タブは「期限切れ／今日／明日／今週／それ以降／日付未定」で自動的にグループ分けされる
- 削除は 🗑️ ボタン、またはリストを左にスワイプ。即削除されるが、直後に出るトーストの「元に戻す」をタップすれば復元できる
- リスト上部の「日付順／優先度順」ボタンで並び替えを切り替えられる

### 📔 ライフログ

- タイムラインの空いている場所をタップ、または ＋ ボタンで記録を追加
- 「やったこと」・開始〜終了時刻・気分（任意）・メモ（任意）を入力
- 保存すると次の記録の開始時刻が自動でセットされ、続けて入力できる（終わるときは「終了」ボタン）
- ‹ › ボタンか日付タップで日を移動して過去の記録も見返せる

### 🔌 家電メモ

- ＋ ボタンで名前・メーカー・型番・購入日・保証期限を登録
- 保証が3ヶ月以内に切れると「保証まもなく切れ」が表示される

### 🧹 掃除手順 / 👕 洗濯手順

- ＋ ボタンでタイトルと手順を登録（1行につき1ステップ）
- リストをタップすると手順が番号付きで表示される

## データの保存について

- データはすべてブラウザの **localStorage** に保存される
- ブラウザのキャッシュ削除・プライベートモードではデータが消えるので注意
- iPhoneとPCのデータは別々（同期しない）
