# データ構造

localStorage に保存するデータの構造をまとめています。

---

## 共通ルール

- すべての項目は `id`（一意な文字列）と `createdAt`（ISO 8601形式）を持つ
- 更新したものは `updatedAt` が追加される
- `Storage.add()` を使うと `id` と `createdAt` が自動付与される

---

## タイムボクシング（`life_timebox`）

```json
{
  "id": "abc123",
  "date": "2026-07-12",
  "title": "資料作成",
  "startTime": "09:00",
  "endTime": "09:30",
  "done": false,
  "gcalEventId": "Googleカレンダーに同期済みの場合のイベントID",
  "createdAt": "...",
  "updatedAt": "..."
}
```

| フィールド | 型 | 値 |
|-----------|----|----|
| date | string | `YYYY-MM-DD`（その予定がある日） |
| startTime / endTime | string | `HH:MM`（24時間表記）。所要時間は常に30分固定（`endTime` = `startTime` + 30分） |
| done | boolean | 完了なら `true` |
| gcalEventId | string | Googleカレンダー同期済みの場合のみ存在 |

タイムライン表示範囲は朝2:00〜夜21:00（`timebox.html` 内の `BASE_HOUR` / `END_HOUR` 定数）。

## ライフログ（`life_lifelog`）

```json
{
  "id": "abc123",
  "date": "2026-07-20",
  "title": "資料作成",
  "startTime": "09:00",
  "endTime": "10:30",
  "mood": "good",
  "notes": "集中できた",
  "createdAt": "...",
  "updatedAt": "..."
}
```

| フィールド | 型 | 値 |
|-----------|----|----|
| date | string | `YYYY-MM-DD`（記録した日） |
| startTime / endTime | string | `HH:MM`（24時間表記、`24:00` まで許容＝日をまたぐ直前の枠）。タイムボクシングと違い所要時間は自由 |
| mood | string | `"great"` / `"good"` / `"neutral"` / `"bad"` / 空文字（未設定） |
| notes | string | 任意メモ |

タイムライン表示範囲は朝2:00〜夜24:00（`lifelog.html` 内の `BASE_HOUR` / `END_HOUR` 定数）。保存すると次の記録の開始時刻が自動で直前の終了時刻にセットされ、モーダルを開いたまま連続入力できる。

## リマインダー（`life_reminders`）

```json
{
  "id": "abc123",
  "title": "薬を飲む",
  "date": "2026-07-01",
  "priority": "high",
  "repeat": "daily",
  "done": false,
  "notes": "朝食後",
  "createdAt": "2026-06-29T10:00:00.000Z",
  "updatedAt": "2026-06-29T12:00:00.000Z"
}
```

| フィールド | 型 | 値 |
|-----------|----|----|
| priority | string | `"high"` / `"medium"` / `"low"` |
| repeat | string | `"none"` / `"daily"` / `"weekly"` / `"monthly"` |
| done | boolean | 完了なら `true` |

## Anki進捗（`life_anki_goal` ＋ `data/anki-stats.json`）

- `life_anki_goal`：1日の目標回数（数値文字列）。未設定時は500。端末間同期の対象
- `anki_page_ui`：グラフの期間などの表示切替（端末ごと・同期しない）
- `data/anki-stats.json`：PCの `tools/anki_export.py` が自動生成（localStorageではなくリポジトリ内のファイル）

| キー | 内容 |
|------|------|
| `history` | `[["YYYY-MM-DD", 回数], ...]` 全期間の日別実践数（AnkiConnect getNumCardsReviewedByDay） |
| `daily` | 直近400日の `{日付: {again, hard, good, easy, new, sec}}`（ボタン別回数・新規枚数・学習秒数） |
| `decks` | `{デッキ名(フル): {日付: 回数}}` 直近400日 |
| `status` | `due`（期日が来たカード）, `newCards`（未学習）, `totalCards` |
| `rolloverHour` | 日付の区切り時刻（AnkiConnectの日別回数と一致する値を自動判定。現在0時） |
| `generatedAt` | データを書き出した日時 |
